# KŌEN

Projeto conceitual e fictício de restaurante japonês contemporâneo para portfólio. Marca, equipe, preços e estabelecimento são imaginários.

## Tecnologias

Next.js App Router, TypeScript, Tailwind CSS, GSAP com ScrollTrigger e next/image. O ambiente de publicação usa Vinext sobre Cloudflare Workers.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run lint
npx tsc --noEmit
npm run build
```

A home está em `/` e o menu completo em `/menu`. As imagens gastronômicas foram criadas para este projeto conceitual.
